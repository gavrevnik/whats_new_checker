# Что дальше?

Локальная фильмотека с бэклогом, оценкой просмотренного и рекомендациями по любимым актёрам и режиссёрам. Активные данные хранятся в SQLite, интерфейс работает на `127.0.0.1`, фильмы обновляются через TMDB, а IMDb rating и краткая сводка наград — через OMDb при наличии ключа.

Сейчас в приложении включены только фильмы. Таблица `content_types` и общий слой `content_items` оставляют место для будущего возвращения музыки, ресторанов и других типов.

## Запуск

На macOS откройте двойным кликом `Whats New Checker.app` или выполните:

```bash
python3 app/server.py --open-browser
```

Адрес приложения: `http://127.0.0.1:8765`.

Новый сервис использует только стандартную библиотеку Python 3.

## Интерфейс

### Бэклог

Таблица показывает русское и оригинальное название, дату выхода, режиссёра в формате `русское имя (original name)`, IMDb rating, жанры, ключевых персон, TMDB ID и прямую ссылку на IMDb (либо TMDB, если IMDb ID ещё неизвестен). Ключевые поля сортируются нажатием на заголовок. Карточка открывается кликом по названию фильма, а «Просмотрено» переносит фильм в следующий раздел. Длинные списки ключевых персон сокращаются до первой персоны и пометки «и др.», но в карточке доступны полностью.

«Актуализировать из TMDB» проходит по всей фильмотеке. Для фильма без TMDB ID сначала выполняется поиск по названию и году, затем обновляются details, credits, genres, runtime, release date, TMDB rating, IMDb ID и совпадения с интересами. Карточка также получает слоган, возрастной рейтинг, актёров, сценаристов, страны, языки, студии, ключевые слова, бюджет и сборы. При настроенном OMDb дополнительно обновляются IMDb rating/голоса, Metascore, касса и краткая сводка awards.

В открытой карточке есть отдельная кнопка «Актуализировать из TMDB» — она обновляет только выбранный фильм.

### Просмотрено

Фильмы разделены на три колонки:

- «Оценить» — реакция ещё не указана;
- «Понравилось»;
- «Не понравилось».

Повторное нажатие текущей реакции снимает её и возвращает карточку в «Оценить». Любую карточку можно вернуть в бэклог. Карточки показывают русское и оригинальное название; клик открывает подробные данные.

### Персоны

Две таблицы содержат любимых режиссёров и актёров: русское и оригинальное имя, TMDB ID. Персону можно добавить вручную. «Актуализировать из TMDB» сверяет имя и ID с англоязычным поиском TMDB, учитывает роль и популярность кандидата, сохраняет русскую локализацию и исправляет ошибочные legacy ID.

### Рекомендации

В LLM-режиме формируется промпт для `$enrich-content-backlog`. В API-режиме актёры и режиссёры выбираются независимо, включая «Выбрать всех». Результат содержит те же поля, что бэклог, и три действия:

- «В бэклог»;
- «Нравится» — сразу в просмотренное с лайком;
- «Не понравилось» — сразу в просмотренное с дизлайком.

## SQLite

Активная база: `data/library.sqlite3`. Описание таблиц и `awards_json`: `data/SCHEMA.md`.

Главные таблицы:

- `content_types`, `content_items`, `movies`;
- `people`, `interest_roles`, `movie_people` (включая метаданные и время последней сверки персон);
- `genres`, `movie_genres`;
- `content_aliases`.

Первичная SQLite-база построена из сохранённых CSV:

```bash
python3 scripts/migrate_csv_to_sqlite.py --force
```

`--force` полностью пересоздаёт активную БД из `legacy/csv/` и удаляет изменения, сделанные после миграции.

## API-ключи

Для локального запуска через `.app` скопируйте безопасный шаблон:

```bash
cp SECRETS.example SECRETS
```

Заполните локальный файл `SECRETS`:

```python
TMDB_API_KEY = "..."
OMDB_API_KEY = "..."
SPOTIFY_CLIENT_ID = "..."
SPOTIFY_CLIENT_SECRET = "..."
```

`SECRETS` добавлен в `.gitignore`; в Git включается только `SECRETS.example` с пустыми значениями. Приложение читает файл без выполнения его как Python-кода.

Переменные окружения имеют приоритет над `SECRETS`:

```bash
export TMDB_API_KEY="ваш_tmdb_ключ"
export OMDB_API_KEY="ваш_omdb_ключ"
python3 app/server.py --open-browser
```

Не храните реальные ключи в notebook, исходном коде или отслеживаемых конфигурационных файлах. Если ключ уже попадал в Git или был опубликован, одного добавления в `.gitignore` недостаточно — ключ необходимо перевыпустить.

TMDB не предоставляет структурированные награды кинофестивалей. Поле `awards_json` не затирается пустым ответом и допускает подключение будущего источника Cannes/Berlinale/Venice без миграции схемы.

## Skills

- `skills/enrich-content-backlog` — подбор и дедупликация фильмов относительно SQLite.
- `skills/add-content-item` — ручное добавление фильма из естественной фразы.

Пример:

```bash
python3 skills/add-content-item/scripts/add_item.py \
  --title-original "The Shining" \
  --title-ru "Сияние" \
  --year 1980 \
  --director "Stanley Kubrick"
```

## Legacy
