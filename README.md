# Что дальше?

Локальная фильмотека с бэклогом, оценкой просмотренного и рекомендациями по любимым актёрам и режиссёрам. Активные данные хранятся в SQLite, интерфейс работает на `127.0.0.1`, фильмы обновляются через TMDB, IMDb rating и краткая сводка наград — через OMDb, а рейтинг и ссылка Кинопоиска — через Kinopoisk API Unofficial.

Сейчас в приложении включены только фильмы. Таблица `content_types` и общий слой `content_items` оставляют место для будущего возвращения музыки, ресторанов и других типов.

## Запуск

Один раз подготовьте локальное окружение для LLM-рекомендаций:

```bash
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
codex login status
```

Последняя команда должна вывести `Logged in using ChatGPT`. Если авторизации ещё нет, выполните `codex login` и завершите вход через браузер.

После этого на macOS откройте двойным кликом `Whats New Checker.app` или выполните:

```bash
python3 app/server.py --open-browser
```

Адрес приложения: `http://127.0.0.1:8765`.

`.app` запускает сервер как отдельный фоновый процесс и при каждом повторном клике открывает новую вкладку с localhost. Если после обновления кода на порту осталась предыдущая версия сервера, launcher проверяет `/api/health`, безопасно перезапускает только процесс `app/server.py` этого репозитория и пишет диагностический журнал в `.runtime/server.log`.

Основное приложение использует стандартную библиотеку Python 3. Для LLM-вызова официальный Codex SDK установлен из `requirements.txt` в локальную `.venv`, которая не попадает в Git.

## Интерфейс

### Бэклог

Таблица показывает русское и оригинальное название, дату выхода, режиссёра в формате `русское имя (original name)`, рейтинги IMDb и Кинопоиска, жанры, ключевых персон и колонку `Link` со ссылками IMDb/КП. TMDB ID убран из таблицы и остаётся в подробной карточке. Ключевые поля сортируются нажатием на заголовок. Карточка открывается кликом по названию фильма. Кнопки «Нравится» и «Не понравилось» сразу переносят фильм в соответствующую колонку раздела «Просмотрено», а значок корзины выполняет обратимое удаление. Длинные списки ключевых персон сокращаются до первой персоны и пометки «и др.», но в карточке доступны полностью.

«Актуализировать из TMDB» проходит по всей фильмотеке. Для фильма без TMDB ID сначала выполняется поиск по названию и году, затем обновляются details, credits, genres, runtime, release date, TMDB rating, IMDb ID и совпадения с интересами. В карточке показываются актёры, сценаристы, страны, ключевые слова, описание и награды. При настроенном OMDb дополнительно обновляются IMDb rating/голоса, Metascore и краткая сводка awards. Если в SQLite ещё нет рейтинга Кинопоиска, тот же процесс делает один запрос к Kinopoisk API Unofficial по названию и диапазону ±1 год, дополнительно сверяя IMDb ID, когда провайдер его возвращает. Уже сохранённый КП-рейтинг повторно не запрашивается.

В открытой карточке есть отдельная кнопка «Актуализировать из TMDB» — она обновляет только выбранный фильм. В форме добавления эту же кнопку можно нажать до сохранения: TMDB заполнит нормализованные названия, сведения и поле `Link` со ссылками TMDB/КП, а ниже покажет рейтинги IMDb/КП, актёров, ключевых персон и описание. TMDB ID и заметки в форме не показываются. Кнопка «Очистить» полностью сбрасывает ручной ввод и найденные данные, оставляя модалку открытой. «Добавить в бэклог» сохраняет фильм в очередь, а кнопки «Нравится» и «Не понравилось» сразу помещают его в соответствующий раздел просмотренного. Если после поиска изменить название или год и нажать актуализацию повторно, приложение выполняет новый поиск по изменённому полю, не используя ID предыдущего результата.

Кнопка «Порекомендовать фильмы» открывает отдельную форму с IMDb rating, диапазоном лет, минимальной длительностью, количеством рекомендаций (по умолчанию 10) и свободным запросом. Перед отправкой приложение автоматически добавляет в промпт понравившиеся фильмы, любимых актёров и режиссёров как мягкий сигнал, а также активный бэклог как список исключений.

Codex возвращает строго структурированный JSON: русское и оригинальное название, год и персональный комментарий. Сервер разбирает его, находит каждый фильм в TMDB, дополняет карточку сведениями TMDB/OMDb/Кинопоиска, повторно проверяет фильтры и исключает дубли. Итог показывается таблицей прямо в модалке; комментарий модели хранится в колонке и поле карточки «Заметка». Название открывает подробную карточку, а кнопки «В бэклог», «Нравится» и «Не нравится» сразу сохраняют фильм в нужный раздел.

### Просмотрено

Фильмы разделены на три колонки:

- «Оценить» — реакция ещё не указана;
- «Понравилось»;
- «Не понравилось».

Повторное нажатие текущей реакции снимает её и возвращает карточку в «Оценить». Любую карточку можно вернуть в бэклог. Карточки показывают русское и оригинальное название; клик открывает подробные данные.

### Персоны

Две таблицы содержат любимых режиссёров и актёров: русское и оригинальное имя, TMDB ID. Персону можно добавить вручную или сначала найти и нормализовать через TMDB прямо в форме добавления; первоначально введённые значения сохраняются как `Raw`. Клик по строке открывает карточку, из которой можно актуализировать только выбранную персону. Общая кнопка «Актуализировать из TMDB» сверяет все имена и ID с англоязычным поиском TMDB, учитывает роль и популярность кандидата, сохраняет русскую локализацию и исправляет ошибочные legacy ID. Значок корзины скрывает выбранную роль персоны из активного списка.

### Корзина

Фильмы и персоны показываются в отдельных таблицах и восстанавливаются одной кнопкой. Удаление мягкое: основные записи, подробные TMDB-данные, жанры и связи не уничтожаются. Содержимое корзины также учитывается при дедупликации рекомендаций, поэтому удалённый фильм не предлагается повторно.

### Рекомендации

В LLM-режиме формируется промпт для `$enrich-content-backlog`. Числовые и жанровые фильтры можно отключать отдельными переключателями: неактивное поле становится серым и полностью исключается из промпта или API-запроса. В API-режиме актёры и режиссёры выбираются независимо, включая «Выбрать всех». Результат содержит те же поля, что бэклог, и три действия:

- «В бэклог»;
- «Нравится» — сразу в просмотренное с лайком;
- «Не понравилось» — сразу в просмотренное с дизлайком.

## SQLite

Активная база: `data/library.sqlite3`. Описание таблиц и `awards_json`: `data/SCHEMA.md`.

Главные таблицы:

- `content_types`, `content_items`, `movies` (включая `raw_json` с первоначальным вводом);
- `people`, `interest_roles`, `movie_people` (включая `raw_json`, метаданные и время последней сверки персон);
- `genres`, `movie_genres`;
- `content_aliases`;
- `trash_entries` — маркеры обратимого удаления со снимком названия для экрана корзины.

Первичная SQLite-база построена из сохранённых CSV:

```bash
python3 scripts/migrate_csv_to_sqlite.py --force
```

`--force` полностью пересоздаёт активную БД из `legacy/csv/` и удаляет изменения, сделанные после миграции.

## API-ключи

Для локального запуска через `.app` скопируйте безопасный шаблон:

```bash
cp SECRETS.example SECRETS
```

Заполните локальный файл `SECRETS`:

```python
TMDB_API_KEY = "..."
OMDB_API_KEY = "..."
KINOPOISK_API_KEY = "..."
SPOTIFY_CLIENT_ID = "..."
SPOTIFY_CLIENT_SECRET = "..."
CODEX_RECOMMENDATION_MODEL = "gpt-5.6-terra"
```

`SECRETS` добавлен в `.gitignore`; в Git включается только `SECRETS.example` с пустыми значениями. Приложение читает файл без выполнения его как Python-кода.

Переменные окружения имеют приоритет над `SECRETS`:

```bash
export TMDB_API_KEY="ваш_tmdb_ключ"
export OMDB_API_KEY="ваш_omdb_ключ"
export KINOPOISK_API_KEY="ваш_kinopoisk_ключ"
python3 app/server.py --open-browser
```

Не храните реальные ключи в notebook, исходном коде или отслеживаемых конфигурационных файлах. Если ключ уже попадал в Git или был опубликован, одного добавления в `.gitignore` недостаточно — ключ необходимо перевыпустить.

TMDB не предоставляет структурированные награды кинофестивалей. Поле `awards_json` не затирается пустым ответом и допускает подключение будущего источника Cannes/Berlinale/Venice без миграции схемы.

## Codex SDK и подписка ChatGPT

LLM-рекомендации запускаются через официальный `openai-codex` в изолированном временном каталоге, с read-only sandbox и запретом подтверждений. SDK использует локальную авторизацию Codex, общую для CLI и IDE extension. При входе через ChatGPT расходуется доступ, включённый в план ChatGPT; `OPENAI_API_KEY` приложению не нужен. Обычный OpenAI Platform API имеет отдельный usage-based биллинг и в этой функции не используется. Ответ ограничен JSON Schema из `app/movie_recommendations.schema.json`; затем приложение выполняет независимое обогащение через TMDB/OMDb/Кинопоиск.

Модель по умолчанию — `gpt-5.6-terra`. Её можно изменить через `CODEX_RECOMMENDATION_MODEL` в локальном `SECRETS` или одноимённую переменную окружения.

## Skills

- `skills/enrich-content-backlog` — подбор и дедупликация фильмов относительно SQLite.
- `skills/add-content-item` — ручное добавление фильма из естественной фразы.

Пример:

```bash
python3 skills/add-content-item/scripts/add_item.py \
  --title-original "The Shining" \
  --title-ru "Сияние" \
  --year 1980 \
  --director "Stanley Kubrick"
```
